# UGC NET Education Papers

A simple, responsive page linking to UGC NET Education (Subject Code 09) question papers and answer keys from 2018–2026.

## Publish with GitHub Pages

After pushing this repository to GitHub, open **Settings → Pages**, select **Deploy from a branch**, then choose the `main` branch and the `/ (root)` folder. GitHub will display the public site URL once the deployment finishes.

## Local preview

Open `index.html` in a modern web browser.

The downloadable paper links point to the sources credited in the page footer.
